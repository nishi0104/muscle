# HuntingGame（Unreal Engine 5 / C++）

リアリティ重視の狩猟ゲームのプロトタイプ。モンハンのように「狩る → 解体 → 素材」を繰り返す流れで、野生動物の感覚・弾道・傷の仕組みは現実に近づけている。

## 動かし方

1. Unreal Engine **5.4** をインストール（5.3〜5.5 でも大きな変更なしで動く想定）
2. `HuntingGame.uproject` を右クリック → **Generate Visual Studio project files**
3. `.sln` を開いて `Development Editor` でビルド → エディタが起動
4. 新規レベルを作成
   - Landscape（地面）と Directional Light / Sky Atmosphere を配置
   - **NavMeshBoundsVolume** で狩場全体を囲む（動物の移動に必須）
   - **PlayerStart** を配置
   - **AnimalSpawner** を数カ所に配置
5. Play

アセットが無くても動く。動物は灰色の箱（胴体＋頭）で表示され、武器はライフルと弓の2種類。

## 操作

| キー | 動作 |
|---|---|
| WASD / マウス | 移動 / 視点 |
| 左クリック | 撃つ（弓は押して引き、離して射る） |
| 右クリック | 構える（ズーム・照準表示） |
| Shift | 走る / 構え中は**息を止める** |
| C / Z | しゃがむ / 伏せる |
| R | 装填 |
| E | 痕跡を調べる / 死体を解体 |
| Q | 武器切替（ライフル ⇔ 弓） |
| Tab | 所持品 |

## リアリティの仕組み

### 動物の感覚（`Animals/WildAnimal.cpp`）
- **視覚**: 視野は約300°。静止した人間は見分けにくく、**動くとすぐ見つかる**。しゃがむ・伏せる・迷彩で見えにくくなる
- **聴覚**: 足音は速く動くほど遠くまで届く。しゃがみ歩きなら数メートルまで近づける
- **嗅覚**: **自分の風下にいる動物には匂いで確実に気づかれる**。右上の矢印で風向きを確認し、風上から近づく。汗をかくと匂いが強くなる
- 警戒度はたまっていく方式。「頭を上げて凝視」されたら動きを止める
- 1頭が逃げると群れ全体が逃げる。銃声でも逃げる

### 弾道（`Weapons/BallisticProjectile.cpp`）
- 重力と空気抵抗（速度の2乗に比例）、**横風による流れ**を計算
- ゼロイン（ライフル100m / 弓20m）。それより遠いと弾は落ちる。弓を引き切らずに射ると下に外れる
- 当たったときの運動エネルギーで貫通の深さが決まる。遠くて力が足りない弾では致命傷にならない

### 傷と出血（`Animals/AnimalSpeciesData.cpp`）
- 弾の通り道が**どの臓器を通ったか**で判定する（斜めから撃つと複数の臓器を貫く）
- 脳は即死、脊椎は倒れて動けなくなる。心臓なら約7秒、肺なら約15秒で倒れるが、**その間に走って逃げる**
- 腹に当たると数分かかり、肉も汚れる。筋肉だけの傷は血が止まり、動物は生き延びる
- 当たった部位は画面に出ない。**血の跡を E で調べて**推測する
  - 泡の混じったピンク → 肺 / 真っ赤な血が大量 → 心臓 / 黒っぽい赤 → 肝臓 / 胃の中身が混じる → 腹
- 手負いの動物は逃げた先で伏せる。**すぐ追うと、また逃げる**

### ハンターの身体（`Player/HunterCharacter.cpp`）
- 照準は呼吸・脈拍・筋肉の震えで揺れる。揺れの大きさは心拍数と姿勢で決まる（伏せ < しゃがみ < 立ち）
- 走ると心拍数が上がり、しばらく狙いが定まらない
- **バックフィーバー**: 獲物をスコープに入れると興奮して心拍数が上がる
- 息を止めると揺れは減るが、長く止めすぎると息が上がって余計に揺れる

### 解体
- 仕留めた動物に近づいて E。肉の量は**肉質**（撃った部位・弾数）で変わる

## 本物のアセットに差し替える

1. **動物**: `WildAnimal` を親にした Blueprint（例: `BP_Deer`）を作る
   - Mesh に四足獣のスケルタルメッシュ、Physics Asset、Anim BP を設定（Anim BP の歩き・走りの切り替えには `GetGaitAlpha()` を使う）
   - `bDebugDrawVitals` をオンにし、`AnimalSpeciesData` の `VitalOrgans` をボーン基準（`Bone` と `Offset`）で配置し直す
   - `FootprintClass` / `BloodClass` / `BedClass` に、`TrackSign` を親にした BP（デカールのマテリアル設定済み）を指定する
2. **種の追加**: `AnimalSpeciesData` の DataAsset を複製する
   - イノシシ: `Temperament=Defensive`、`AttackDamage=35`、`MinBulletEnergyJ=1600`
   - クマ: `Temperament=Aggressive`、`AttackDamage=70`、`MaxHealth=250`、`MinBulletEnergyJ=2700`
3. **武器**: `HuntingWeapon` / `HuntingBow` を親にした BP でメッシュ・音・弾薬を設定し、ハンター BP の `WeaponClasses` に登録する
4. GameMode の `DefaultPawnClass` をハンター BP に変更する
